## hz-01 Money, numbers & representation — 4 GAP, 1 COVERED

- `domain/auth/user/email.py:20` — `str.lower()` не зависит от локали, Java
  `toLowerCase()` без `Locale.ROOT` зависит. Guard: тест кейс-фолдинга email под
  локалью `tr-TR`.
- `email.py:35-39` `masked()` — `local[:1]` режет по code point, Java
  `substring(0,1)` по UTF-16. Guard: тест маскирования local-part вне BMP.
- `adapter_email/sender.py:20` — Python сам подбирает charset; Jakarta Mail — нет.
  Guard: тест отправки кириллического тела с проверкой сырых SMTP-байт.
- `domain/auth/challenge/challenge.py:42` `ttl_seconds()` — деление→ceil без
  теста на нецелую разницу. Guard: тест с дробной TTL.
- COVERED: `challenge_store.py:58` `_retry_after_seconds` закрыт существующим
  `test_should_report_retry_after_rounded_up_when_cooldown_is_held`.

## hz-02 Transaction boundary, external calls & idempotency — 3 GAP

- `@Transactional` по умолчанию откатывает только на unchecked; `UnitOfWork.__aexit__`
  откатывает на любом исключении. Guard: тест `issue_session` с checked-исключением.
- `SWAP_CHALLENGE_TEMPLATE` сравнивает `createdAt` лексикографически против
  `isoformat()` (`+00:00`); Java-сериализатор с `Z` ломает разрешение гонки.
- Нигде нет таймаутов на блокирующих SMTP/JDBC/Redis после async→blocking.

## hz-03 Concurrency, consistency & distribution — 2 GAP

- Четыре Redis RMW-операции атомарны только благодаря одному `EVAL`. Guard:
  тест с двумя конкурентными вызовами через барьер на каждой операции.
- `session_issuance.py` `_link_user` — SELECT-then-INSERT без обработки
  `IntegrityError`/`ConstraintViolationException` нигде. Guard: тест на две
  конкурентные верификации с одним ключом уникальности.

## hz-04 Schema & contract evolution — 4 GAP

- `auth.t_users.email` — функциональный уникальный индекс на `lower(btrim(email))`,
  не простой UNIQUE. Наивный перенос в Liquibase меняет поведение.
- Enum `auth.user_gender` — политика вне домена.
- Legacy nullable `expires_at` — путь forward-compat.
- Общая DDL-парность на замене Alembic → Liquibase.

## hz-05 Request boundary & input — 3 GAP

- `challengeId`/`code`/`refreshToken` типизированы `Any`, `extra="ignore"|"allow"`.
  Типизированный Jackson-DTO ужесточает границу молча.
- Гвард подключён точечно через `Depends` (opt-in), а идиоматичный Spring-фильтр
  matched по URL (opt-out) → fail-open на непокрытом маршруте.
- Конверт ошибок не покрывает Jackson/Bean-Validation отказы: отвечает
  Whitelabel/ProblemDetail вместо `{code,message,payload}`.

## hz-06 Resource limits & backpressure — 5 GAP

- Пулы (`pool_size=10`, redis `max_connections=20`) за неограниченными
  виртуальными потоками; `command_timeout=5.0` не имеет JDBC-эквивалента;
  Tomcat/Jackson накладывают лимиты тела и строки, которых нет у Starlette.

## hz-07 Time, operability & disclosure — 4 GAP

- `SessionPolicy.truncate()` роняет микросекунды, Java `Instant` держит нано.
- Spring `/error` Whitelabel раскрывает внутренности там, где FastAPI отдавал 500.
- Config drift: pydantic падает на старте, Spring без `@Validated` биндит null;
  `infrastructure/.env` использует недефолтные порты 8001/5433/6380/1026.
- `created_at`/`updated_at` идут от часов БД; `@CreationTimestamp` перенёс бы их
  на часы JVM.
