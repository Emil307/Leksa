## Принятые решения по стеку

| Вопрос | Решение | Почему |
|---|---|---|
| Корневой пакет | `com.uwords` | шаблоны биндинга используют `com.example` как плейсхолдер |
| Сборка | Gradle multi-module, toolchain 21, `bootJar` только у `:backend:application` | остальные модули — библиотеки |
| Проверка слоёв | ArchUnit в отдельном модуле `:backend:architecture` (только `src/test`) | замена `.importlinter`; ловит и «нет фреймворка в domain/usecase», и «usecase не зовёт usecase» |
| Web | Spring Boot 3 Web MVC, `spring.threads.virtual.enabled: true` | блокирующий стиль, без реактивности |
| Redis | `spring-boot-starter-data-redis` (Lettuce, синхронный `StringRedisTemplate`) | пул и таймауты через `spring.data.redis.*`; **без** `@EnableRedisRepositories` — keyspace-нотификации делают `CONFIG SET`, а `infrastructure/redis/redis.conf` содержит `rename-command CONFIG ""` |
| Lua-скрипты | переносятся дословно в `adapters/cache/src/main/resources/redis/*.lua`, исполняются `DefaultRedisScript` | атомарность RMW-операций сохраняется; подстановка плейсхолдеров строго `String.replace`, **не** `String.format` (в `claim-attempt` есть `%s` внутри Lua-паттерна) |
| SMTP | `spring-boot-starter-mail`, `MimeMessageHelper(msg, false, "UTF-8")` | тот же `text/plain; charset=UTF-8` и RFC 2047 тема; unit-тесты на GreenMail |
| Auth-гвард | `HandlerInterceptor` + `HandlerMethodArgumentResolver`, **без** Spring Security | `Filter` работает вне `DispatcherServlet` и не попадает в `@RestControllerAdvice` → 401 разъезжается по формату; интерцептор даёт байт-в-байт то же тело |
| JWT | `jjwt`/`nimbus`, HS256, подпись проверяется, `exp`/`aud` — **нет** | истечение и аудиторию проверяет домен через `ClockPort`, как сейчас |
| Health | собственный `@RestController` на `/health`, тело `{"status","database"}` | `/actuator/health` из биндинга даёт другой путь и другое тело → `technology.md` переопределяет биндинг |
| Миграции | Liquibase changelog с нуля, `spring.liquibase.enabled=false` | приложение не мигрирует на старте, как и сейчас; отдельная gradle-задача из `migrate.sh` |
| Время в БД | `@DynamicInsert` + `insertable=false` на `created_at`/`updated_at` | часы остаются серверными (`server_default=func.now()`), а не JVM-ными |
| Persist | `entityManager.persist()`, **не** `save()` | `save()` превращает вставку дубликата PK в тихой UPDATE |
| Ассоциации JPA | нет ни одной, `ddl-auto=validate` | адаптер остаётся плоским, как сейчас |
