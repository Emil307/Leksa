## Plan correction

Чекбокс предполагал «только @Service и @Transactional, StartAuthChallengeService.start намеренно
без @Transactional». Полоса не нашла ни одного места, куда `@Transactional` можно поставить
без изменения поведения, и это подтвердилось независимой проверкой родителя:

- `grep -rl "transaction\|unit_of_work" backend/usecase/src/usecase/` -- пусто. Python-usecase
  транзакции не размечает вообще.
- `backend/adapters/storage/src/adapter_storage/repositories/_base.py::_transaction` открывает
  `UnitOfWork()` на каждый вызов репозитория, если внешний UoW не передан, и `unit_of_work.py`
  коммитит на выходе. То есть демаркация -- одна транзакция на вызов репозитория, в адаптере.

Добавление `@Transactional` на сервис слило бы эти вызовы в одну транзакцию и, в частности,
сломало бы компенсацию `discardStartedChallenge` в `start`, которая корректна только потому,
что постановка в очередь падает вне транзакции. Refactor-задача менять поведение не может,
поэтому `@Transactional` нет нигде. Текст чекбокса исправлен.

**Следствие для Step 5:** Java-репозитории обязаны коммитить на каждый вызов, а не полагаться
на транзакцию уровня usecase. Ставить `@Transactional` на сервисы задним числом нельзя.

## Divergences

- `X | None` на границе портов -> `Optional<T>`. Два места в Python разыменовывают `None`
  без проверки (`_strategy_for`, `_claim` в `verify_challenge.py`): `AttributeError` -> 500.
  В Java `.orElseThrow()` -> `NoSuchElementException` -> 500. Наблюдаемо то же, обе ветки
  недостижимы в зелёном сценарии.
- Кортежи журнала вызовов -> records (`CooldownArguments`, `ClaimArguments`,
  `RememberedVerification`), чтобы `equals` воспроизвёл равенство кортежей в ассертах.
- `except Exception` -> `catch (RuntimeException)` в `enqueueOrDiscard`: порт не объявляет
  checked-исключений.
- Порядок вызовов в `VerifyAuthChallengeService.issueSession` сохранён буквально
  (`refreshTokens.generate()` до обоих `ids.newId()`) -- фейки суть упорядоченные очереди.
- `conftest.py` (2 файла) растворены в `@BeforeEach`; `__init__.py` (11 файлов) эквивалента не имеют.
- `statements/auth.py` разбит на `StartChallengeStatements` + `StartChallengeFixtures` под лимит 200 строк.
