Термины:

1. Тест - детерминированный набор вопросов с вариантыми ответов, правильный ответ/ответы заранее известны.
2. Слово - единица контента, может содержать изображение, содержит массив переводов, опредляющий список языков, для которых поддерживается слово
3. Перевод слова - объект, содержащий аудио версию, текстовую версию, а также транскрипцию, значение, форму, число и тд на языке к которому принадлежит перевод

4) Глобальный словарь - место, где хранятся все слова и их переводы
5) Пользовательский словарь - место где хранятся ссылки на слова из глобального словаря.
6) Тренировка - набор заданий для тренировки конкретных слов. У каждой тренировки есть тип.

Сайт

Тест на знание языка:

1. вставить пропущенное слово
2. Дается 4 слова и 4 перевода, нужно соотнести слова с переводами
3. прочитать текст и ответить на вопросы (дается вопрос и список вариантов ответов)
4. прослушать аудио и выбрать ответ из списка (дается вопрос и список вариантов ответов)
5. собрать слово из букв по картинке

Приложение

Тренировки:

1. Синонимизатор - дается слово и его аудио версия, нужно выбрать из списка слов синоним для этого слова (дается вопрос и список вариантов ответов)
2. Словомания - дается слово и перевод, задача выбрать правильный это перевод или нет

3) Дается слово его аудио версия и картинка, нужно выбрать из списка переводов правильный для этого слова (дается вопрос и список вариантов ответов)
4) Сбор слова по картинке - дается слово на родном для пользователя языке, картинка и набор букв, нужно собрать слово
5) Сбор слова по аудио - дается слово на родном для пользователя языке, аудио и набор букв, нужно собрать слово
6) Дается 4 слова и 4 перевода, нужно соотнести слова с переводами
