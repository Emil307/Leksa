## 2. Чужой текст отрисовывается как текст

### 2.1 Формулировка сервиса в ответе об ошибке не выводится и не исполняется

Tier: 3 (sec:XSS) — формулировка приходит от собственного бэкенда, который её не исполняет во вред себе, и по решению истории вообще не выводится; вектор требует подмены ответа сервиса; не установлено «не редко».

```gherkin
Дано пользователь на экране <экран>
И сервис отвечает <ответом> с формулировкой, содержащей разметку и скрипт
Когда он выполняет действие экрана
Тогда видно только собственное сообщение приложения для этого ответа
И формулировка сервиса в разметке страницы отсутствует, скрипт не выполнен
```

| экран | ответ |
|---|---|
| почты | адрес не принят |
| почты | сервис недоступен |
| кода | проверка отклонена |
| кода | сервис недоступен |

### 2.2 Введённый адрес показывается на экране кода как текст

Tier: 3 (sec:XSS) — адрес с разметкой вводит сам пользователь и видит его сам — self-XSS без второй жертвы; тяжесть последствия не установлена.

```gherkin
Дано пользователь на экране почты ввёл адрес с разметкой, похожий на адрес
Когда он нажимает «Получить код»
Тогда на экране кода адрес показан посимвольно как введён
И разметка из адреса не создала элементов и не выполнила скрипт
```
