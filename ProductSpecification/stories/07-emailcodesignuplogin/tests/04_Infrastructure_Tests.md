## 1. Сервис недостижим

### 1.1 Нет соединения с сервисом — то же сообщение о недоступности, действие можно повторить

Tier: 2

```gherkin
Дано пользователь на экране <экран> подготовил действие
И сервис недостижим: соединение обрывается без ответа
Когда он выполняет действие экрана
Тогда видно сообщение «Сервис временно недоступен, попробуйте позже» без подробностей
И кнопка действия снова доступна
И введённые данные сохранены
```

| экран |
|---|
| почты — введён адрес, действие «Получить код» |
| кода — введён код, действие «Подтвердить» |

---

## DSL Technical Reference

| DSL Statement | Technical Implementation |
|---|---|
| `сервис недостижим: соединение обрывается без ответа` | стаб для этого адреса обрывает соединение (fault `CONNECTION_RESET_BY_PEER` / пустой ответ); `fetch` отклоняется сетевой ошибкой, стаб для остальных адресов работает |
| `сообщение … без подробностей` | текст не содержит `Failed to fetch`, кода статуса и адреса API |
