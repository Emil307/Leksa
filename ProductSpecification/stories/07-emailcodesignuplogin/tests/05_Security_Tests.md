# EmailCodeSignupLogin — тесты безопасности

> **Implementation Order**: Tests are numbered for sequential TDD implementation.
> Start с того, что фронт не хранит и не показывает секреты сессии, затем — что чужой
> текст (формулировки сервиса и введённый адрес) отрисовывается как текст, а не разметка.

**Граница истории.** Поверхность — публичный клиент без собственных секретов. Бэкенд
не меняется: границы ввода, инъекции, лимит попыток, кулдаун и нераскрытие причины
`401` закрыты тестами безопасности истории 01 и здесь не переутверждаются. Проверка
на фронте (адрес похож на адрес, шесть цифр) — только удобство; сервер валидирует
сам, и это уже утверждено там же.

**Отфильтровано как неприменимое** (не пишем сценарии): CSRF — bearer-токен в памяти,
куки нет; SQL/NoSQL-инъекции, mass assignment, IDOR — у фронта нет хранилища и нет
ресурсов с идентификаторами; хеширование паролей — пароля нет; rate limiting — на
стороне сервера, история 01; общие заголовки безопасности, CORS, HTTPS — сквозные.

## 1. Секреты сессии

### 1.1 Токены и идентификаторы не появляются ни на экране, ни в хранилищах браузера

Tier: 2 (sec:JWT)

```gherkin
Дано пользователь прошёл путь от экрана почты до экрана «вошёл»
Тогда ни на одном из трёх экранов в разметке нет значений accessToken, refreshToken, идентификатора сессии и идентификатора запроса кода
И в localStorage, sessionStorage и cookie ничего не записано
И после перезагрузки страницы сессии нет — виден экран почты
```

## DSL Technical Reference

| DSL Statement | Technical Implementation |
|---|---|
| `в разметке нет значений …` | `driver.getPageSource()` не содержит `accessToken`/`refreshToken`/`session.id`/`challengeId` из ответов стаба |
| `в localStorage, sessionStorage и cookie ничего не записано` | `window.localStorage.length == 0`, `sessionStorage.length == 0`, `driver.manage().getCookies()` пуст |
| `формулировка, содержащая разметку и скрипт` | `message: "<img src=x onerror=window.__pwned=1>"` в конверте 400/401/503 |
| `скрипт не выполнен` | `window.__pwned` не определён; в DOM нет элемента `img[src=x]` |
| `адрес с разметкой, похожий на адрес` | `"<b>x</b>"@example.test` — проходит локальную проверку «похож на адрес», стаб принимает |
| `адрес показан посимвольно как введён` | текст элемента адреса равен введённой строке, `b`-элемента внутри нет |
