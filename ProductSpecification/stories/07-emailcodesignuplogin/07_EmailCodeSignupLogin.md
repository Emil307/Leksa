# Регистрация и вход по коду из письма в приложении

## Brief Description

Пользователь входит в приложение Uwords по своей почте без пароля: вводит адрес, получает
письмо с кодом, вводит код — и оказывается внутри. Новый он или уже был — незаметно: один
поток и для регистрации, и для входа.

## Flow

1. Пользователь открывает приложение и видит экран ввода почты.
2. Вводит адрес и нажимает «Получить код».
3. Приложение показывает экран ввода кода: на какой адрес ушло письмо, обратный отсчёт до
   истечения кода, кнопку «Отправить новый код» и ссылку «Изменить адрес».
4. Пользователь вводит шесть цифр из письма и нажимает «Подтвердить».
5. Код принят — пользователь оказывается внутри приложения.
6. Код не принят — приложение сообщает об этом, поле остаётся открытым для новой попытки.
7. Обратный отсчёт дошёл до нуля — поле кода закрывается, доступна только «Отправить новый код».
8. «Отправить новый код» — уходит письмо с новым кодом, прежний перестаёт действовать,
   отсчёт начинается заново. Если пауза между отправками ещё не прошла, письмо не уходит,
   а кнопка закрывается на время, которое назвал сервис.
9. «Изменить адрес» возвращает на первый экран с уже введённым адресом.

## Acceptance Criteria

- Один и тот же путь ведёт внутрь и нового, и существующего пользователя; экран не различает их.
- Отклонённый код показывается одним безопасным сообщением без объяснения причины.
- Пока идёт запрос, кнопка недоступна и повторное нажатие второго запроса не создаёт.
- После входа пользователь видит экран продукта; ни один секрет сессии на экране не появляется.
- Повторное открытие приложения начинается с экрана ввода почты — сессия между открытиями не хранится.

## Validation Rules

| Поле | Правило |
|------|---------|
| Почта | Непустая и похожа на адрес — иначе кнопка «Получить код» недоступна. Адрес, который сервис не принял, показывается как «Проверьте адрес» |
| Код | Ровно шесть цифр — иначе кнопка «Подтвердить» недоступна. Ведущий ноль значим |

## Screen States

- **Почта**: пустая · заполняется · отправка · ошибка адреса · сервис недоступен · пауза между отправками ещё не прошла.
- **Код**: ожидание ввода (с отсчётом) · отправка · код отклонён · код истёк (поле закрыто) · повторная отправка недоступна / доступна · сервис недоступен.
- **Внутри**: пользователь вошёл.

## Core Requirements

- Приложение открывается на телефоне внутри Telegram; раскладка — одна, мобильная.
- Срок жизни кода и пауза между отправками задаются сервисом и показываются как есть; приложение их не выдумывает.
- «Сервис временно недоступен» — одно сообщение и возможность повторить действие, без подробностей.
- Перезагрузка страницы на экране кода возвращает к экрану почты; код из старого письма после этого не действует.
