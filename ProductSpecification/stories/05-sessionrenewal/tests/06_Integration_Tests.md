# SessionRenewal — Integration Tests

> **Implementation Order**: Tests are numbered for sequential TDD implementation.
> Сначала связываются REST, подпись и хранилище, затем закрепляются конкурентный и потерянный ответы.

---

## 1. Сквозная ротация

### 1.1 Успешный запрос согласованно обновляет хранилище и выпускает JWT

Tier: 1 (hz-01)

```gherkin
Дано в реальном хранилище существует действующая сессия
Когда клиент обновляет токены через приложение
Тогда REST-ответ содержит прежний идентификатор сессии и новую пару
И в той же строке хранилища совместно сохранены новый refresh-токен и новый срок
И новый access-токен проверяется с прежними пользователем и сессией
И старый refresh-токен больше не действует
```

### 1.2 Условная запись разрешает только одного конкурентного победителя

Tier: 2 (hz-03, hz-04)

```gherkin
Дано две независимые операции хранилища используют один исходный refresh-токен
Когда их условные обновления выполняются с детерминированным чередованием
Тогда одна операция изменяет одну строку
И вторая операция не изменяет строк
И сохранённые токен и срок принадлежат одной полной ротации победителя
```

### 1.3 Потерянный успешный ответ не допускает второй ротации

Tier: 2 (hz-02, hz-03, hz-04)

```gherkin
Дано успешная ротация зафиксирована, но её ответ потерян
Когда клиент повторяет запрос со старым refresh-токеном
Тогда повтор имеет единую ошибку авторизации
И в хранилище присутствует ровно одна полная ротация
И новая пара первого запроса остаётся действительной
И повтор не отзывает и не заменяет эту пару
```

## DSL Technical Reference

| DSL Statement | Technical Implementation |
|---------------|-------------------------|
| `реальное хранилище` | PostgreSQL-backed acceptance environment |
| `через приложение` | `POST /api/v1/auth/token/refresh` through composed FastAPI app |
| `проверяется` | JWT HS256 signature and exact `sub`, `sid`, `exp` decoding |
| `условное обновление` | Atomic SQL update constrained by `refresh_token` and `expires_at > now` |
| `не изменяет строк` | Affected-row count is `0`, mapped to `UNAUTHORIZED` |
| `полная ротация` | One committed pair of `refresh_token` and `expires_at` |
