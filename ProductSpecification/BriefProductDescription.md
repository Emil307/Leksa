# Краткое описание продукта

1. Uwords — персональная платформа для изучения языков, которая заставляет
   пользователя заговорить. Первая версия предназначена для английского языка,
   но продукт и его архитектура изначально рассчитаны на мультиязычность.
2. Основная аудитория — пользователи 16–35 лет с уровнем A2–B2, которые уже
   изучали язык, но пока не могут уверенно применять свои знания в живой речи.
   Uwords помогает им заниматься короткими сессиями без зубрёжки и превращать
   пассивный словарный запас в активный.
3. Центр обучения — персональный словарь. Пользователь сам выбирает слова для
   добавления из нескольких источников:
   - рекомендаций, полученных после анализа его речи;
   - переводчика и поиска по глобальному словарю;
   - новых слов, встретившихся во время игр;
   - диалога с AI-репетитором, где любое слово можно сохранить нажатием.
4. Слова из персонального словаря можно тренировать целенаправленно или изучать
   в играх, где они перемешиваются с новой лексикой. После каждой игры
   пользователь видит встретившиеся слова и решает, какие из них добавить в
   свой словарь.
5. Изученную лексику пользователь применяет в общении с AI-репетитором. Так
   Uwords создаёт повторяющийся цикл: обнаружить нужное слово → добавить в
   словарь → закрепить в тренировках и играх → использовать в разговоре.
